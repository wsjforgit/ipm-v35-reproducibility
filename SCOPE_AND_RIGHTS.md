# Rights and verification scope

Code and derived numerical result files in this capsule were selected from the submitting author's prepared reproduction project with explicit authorization to share cleared originals. Rights for third-party biomedical source texts, benchmark qrels, medical product labels, and upstream software are NOT represented as transferred. These third-party items are absent.

The RUNS.json files contain identifiers and model-generated scores, not source passages or original clinical-record text. Do not conflate availability of rank outputs with a right to distribute upstream inputs.

This version provides deterministic saved-output replay, not complete independent regeneration of neural inferences. No real clinician adjudication, clinical efficacy or patient-level safety validation is included.

Before public deposit, select and declare an appropriate license for the author's original code and derived outputs and verify repository anonymity for double-anonymous review.
